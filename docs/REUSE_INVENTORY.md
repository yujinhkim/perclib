The canonical configuration is `Set (Sym2 V)`, its law is `prodBernoulli q` for arbitrary `q : Sym2 V → unitInterval`, and its graph is `SimpleGraph.fromEdgeSet ω`. Reachability clusters contain their base vertex. Diagonal probabilities are arbitrary: loops have no graph effect, but the underlying coordinates remain part of the product space. Basic definitions should not acquire countability assumptions merely to match an upstream proof; impose these only where the measurable/countable argument requires them. Volumes and expectations are `ℕ∞` and `ℝ≥0∞`, respectively.

## Concrete reuse boundaries

1. **Probability foundation:** native Bernoulli uses lattice Boolean coordinates and a homogeneous infinite product. Vendored Literature uses Set/Sym2 coordinates, but a host-masked homogeneous law. Neither is an excuse to redefine D-2. For Boolean helpers, specify the measurable equivalence between Set configurations and membership indicators and prove its law transport; for a lattice embedding, distinguish represented bonds from other Sym2 coordinates. Existing canonical marginals are preferable when they avoid this bridge.
2. **T-2 association:** the finite Harris argument is general in the finite index, not the coordinate parameter. The open-event extension has an explicit finite-witness exhaustion hypothesis. Full countable increasing-event association needs a separate approximation argument or stronger reusable theorem. An infinite-cluster event need not have a finite forcing certificate; confusing it with escape from a finite set would invalidate the extension.
3. **T-3 BK:** finite certificates, their restriction equivalence, and the directed truncation proof are valuable general-index material. Distinguish the low-density file, all-parameter homogeneous extension, and strictly bounded profile extension. A uniform bound below one is not part of D-2. The homogeneous endpoint theorem does not discharge arbitrary mixed-profile endpoints. Keep the finite-certificate definition of disjoint occurrence explicit.
4. **T-4 Russo:** reuse finite product differentiation before the conductivity wrapper. The desired beta-dependent law requires differentiating each coordinate probability. Endpoint conditions and summability/limit interchange for infinite systems are new obligations; no finite homogeneous theorem silently settles them.
5. **T-5 sharpness:** use the DCT source as an argument reference and a source of generic finite-domain dependence/path lemmas. Its actual sharpness conclusion concerns nearest-neighbour distance decay. For a long-range power-law kernel a direct edge already prevents that general conclusion. This is a mismatch of reusable source with target, not a proposal to change the roadmap. A long-range proof must supply its own boundary/tail argument and appropriate target conclusion.

The SharpnessDCTProofs file's introductory roadmap mentions additional tilde-critical discussion, but no `tildeCriticalProb` declaration is supplied there at this revision.
